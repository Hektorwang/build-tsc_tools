## 删除 fping 相关内容的计划

背景（已排查确认）：fping 无任何功能依赖，涉及 4 个被 git 跟踪的文件 + 2 处文档引用 + 1 个生成产物。

### 修改步骤

1. **删除 tsc_fping 模块**（纯文档展示模块，仅一行 `glow readme.md`）
   - `git rm -r tsc_tools/modules/tsc_fping/`（readme.md + run.sh）

2. **删除 fping 二进制**
   - `git rm -r tsc_tools/packages/fping/`（fping-aarch64、fping-EL78-x86_64，约 2.3MB）

3. **修改安装清单** `tsc_tools/packages/install.sh`
   - 删除第 15 行 `["fping"]="-v"`（SUPPORTED_BINARY_TOOLS 关联数组条目）

4. **修改项目文档** `README.md`
   - 删除第 28–30 行的 tsc_fping 模块介绍块（3 行）

5. **更新发版记录** `tsc_tools/release-note.md`
   - 顶部新增条目：
     ```
     ## Version=2.1.2

     1. refactor: 移除 fping 相关内容（tsc_fping 模块、二进制及安装清单条目）
     ```
   - 下次 build.sh 打包产物将命名为 tsc_tools-2.1.2-noarch-<日期>.sh

6. **重新生成 rag.md**（gitignored 构建产物，build.sh 本来也会重建，这里保持工作树一致）
   - 执行 `./gen_rag.sh`

### 不需要改的地方（已确认）

- `tsc` 分发器自动按目录发现模块，无硬编码，删除目录即自动从帮助中消失
- `tsc_tools/README.md` 是根 README 的构建副本（gitignored），build.sh 会覆盖
- 已部署机器上残留的 `/bin/fping`、`/home/tsc/tsc_tools/bin/fping` 属于部署侧清理，不在本仓库范围

### 验证

- `grep -ri fping`（排除 .git/ 和 release/）应无结果
- `bash -n tsc_tools/packages/install.sh` 语法检查
- 运行 `./tsc_tools/tsc`（无参数）确认模块帮助列表不再出现 tsc_fping
